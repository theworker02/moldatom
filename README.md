# moldatom

Mold encode/decode helpers for atom payloads in pipelines.

**Site:** https://theworker02.github.io/moldatom/

## Install / run

```bash
git clone https://github.com/theworker02/moldatom.git
cd moldatom
node src/cli.js
node --test
```
